# Triage Labels

The engineering skills use five canonical triage roles. This table maps each role to the label used in this repository.

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | The issue is waiting for information from its reporter |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and ready for an implementation agent |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or intervention |
| `wontfix` | `wontfix` | The issue will not be actioned |

When a skill names a canonical role, use the corresponding repository label. Creating or modifying labels on GitHub remains an explicit tracker mutation and requires user authorization.
